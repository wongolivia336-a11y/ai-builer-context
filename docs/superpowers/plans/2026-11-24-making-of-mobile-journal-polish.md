# 制作过程页手账与移动端润色计划

**目标：**让制作过程页与首页共享同一套品牌页眉和玻璃按钮，五个阶段各自只展示对应的手账文字，并为手机端提供稳定清晰的球体与阅读布局。

**范围：**`MakingOfPage`、其样式、球体几何、`docs/demo-scope.md`。不改其他页面、不新增依赖。

## 步骤

1. 将页眉字标与产品介绍组合为首页同款纵向品牌区；删除实验标签和边注，按钮沿用首页玻璃按钮尺寸与外观。
2. 手账只渲染当前阶段的原文，使用 Zine 已打包的文楷字体；为纸张增加细纤维、柔和色差、自然不规则边缘和四角轻翘的明暗层次。
3. 阶段控件改为语义化 tabs：鼠标可悬停预览、点击固定选择、方向键切换；触屏不依赖 hover/leave，切换不会清空新状态。
4. 手机端增加“球体 / 手账”视图切换，给球体和文字各自留出完整区域；适配安全区、窄屏、横屏及较短视口。
5. 更新 Demo 范围说明；运行生产构建，并在桌面和手机视口手动走查标签、拖拽/滚轮、手账阅读、返回和分页，再提交并推送当前功能分支。

## 验收

- 五个阶段的正文互斥显示，点击/悬停/键盘/触屏切换行为稳定。
- 桌面页眉和按钮沿用首页视觉；手机页眉、切换、章节 tab、分页均可见且可点。
- 生产构建成功；桌面及手机浏览器走查无视口溢出、控件重叠或章节状态错位。

## 实际验证

- `npm run build` 成功；仅有项目既有的主 JavaScript chunk 大于 500 kB 提示。
- Edge 手动走查 390 × 844、360 × 740、844 × 390 和 1440 × 900；所有视口均无横向溢出，横屏纸页已避开品牌区。
- 真实触控事件选中第五个页签成功；五个页签依次切换到各自标题与正文，正文始终只渲染一个章节。
- 桌面鼠标悬停可切换阶段，移开后选中阶段保持；检查到 Zine 文楷与 Marker 字体均已加载。
