# 用户提供素材接入表

这组素材作为浏览器 Demo 的场景图、轻量装饰和内容缩略图使用。首页的可点按泡泡继续由 CSS 与交互状态实时绘制，避免贴图覆盖碰撞、筛选和戳破反馈。

| 素材 | 项目文件 | 使用位置 | 用法 |
| --- | --- | --- | --- |
| 林间撕纸拼贴 | `sound-postcard-collage.webp` | 漫游捕捉成功卡片 | 作为声音明信片缩略封面，给捕捉结果增加可记忆的视觉内容。 |
| 手绘贴纸总图 | `handdrawn-stickers.webp` | 素材包 | 保留整张贴纸图供后续裁切；目前抽出两颗星贴纸用于录音状态。 |
| 薄荷、蓝色星星 | `sticker-star-mint.webp`、`sticker-star-blue.webp` | 共创录音泡泡周围 | 轻轻漂浮；录音时随声音节奏轻微抖动。 |
| 夜间林道竖图 | `roam-night-portrait.webp` | 手机漫游取景 | 作为手机比例的街道环境底图，承托 AR 泡泡和瞄准框。 |
| 夜间林道横图 | `roam-night-landscape.webp` | 现场大屏镜像 | 同场景的横构图版本，投屏时保留完整路径纵深。 |
| 树叶与天空留白图 | `create-open-sky.webp` | 共创页与共创大屏镜像 | 为录音页提供轻、亮的自然底图，中心留白让录音泡泡和状态信息清晰。 |
| 薄虹彩泡泡圈 | `bubble-rim-thin.webp` | 漫游选中的目标、捕捉结果封面 | 只标记当前目标，维持轻薄质感，不给全部泡泡增加厚边。 |
| 珍珠厚圈与薄荷圈 | `bubble-rim-pearl.webp`、`bubble-rim-mint.webp` | 回声榜缩略泡泡 | 对榜单内容做轻量材质区分；不用于整屏泡泡场。 |

| 新 moodboard：透明心形、星形、花形、云朵形物件 | 对话附件中的参考图；未作为贴图导入 | Gallery 主泡泡与 AR 叠层 | 提取形态与珍珠/虹彩 CMF 语言，用 CSS + SVG 实时绘制；主泡泡仍有挤压、碰撞、戳破反馈。 |
| 新 moodboard：晴空、街景与 2D 涂鸦叠加 | 对话附件中的参考图；部分街景复用既有照片素材 | 漫游 AR 风格取景 | 参考“实景照片 + 2D 插画泡泡”的空间层次；入场补上扫描与缓冲状态。 |

## 视觉边界

- 环境照片带来真实空间感，但以柔和遮罩压低对比，避免抢过声音目标和文字。
- 贴纸仅放在录音泡泡附近，不覆盖录制按钮、波形或状态文案。
- WebP 泡泡资产只用于局部状态和缩略图。首页主要泡泡保留 CSS 绘制，以继续响应碰撞、筛选、点按和爆破动画。
- 本轮 moodboard 的形状图、整页参考图和物件拼贴作为视觉方向，不直接铺成静态界面素材；首页异形泡泡、横向卫星轨道标签和 AR 插画由页面实时生成。
- `roam-night-portrait.webp`、`roam-night-landscape.webp` 和 `create-open-sky.webp` 是静态演示底图，不代表实时相机、GPS 或 ARKit 场景锚定。
- 本轮素材接入浏览器 Demo。SwiftUI 文件目前没有配套 Xcode 工程或资源目录，暂不引用这些图片；后续若要在原生工程预览，需将对应文件放入 Asset Catalog。
