# Demo 范围与实现状态

## 当前已有

- 浏览器端 Vite + React 可交互视觉演示。
- 泡泡、漫游、共创三页的信息架构。
- 首页是个人声音 Gallery：珍珠球、心形、星形、花形、云朵形以不同大小全屏漂浮，模拟泡泡碰撞、墙面反弹；用户可直接拖动泡泡，泡泡相交时朝接触点挤压、形成短暂液膜并回弹。戳破有朝触点打开的薄膜裂口、卷曲液膜和重力水滴的视觉模拟，随后播放合成声音并重新浮现。每颗泡泡都有沿自身轮廓环转的文字，心形、星形、花形和云朵分别贴合异形外沿；文字在远侧压到泡泡后方，转到近侧清晰显示。焦点泡泡的轨道可手动拖动并显示更多留言信息。
- 内容筛选以动态虚线圈出匹配泡泡、压暗其他泡泡；“全部”恢复全色泡泡场。回声榜同时呈现收藏和评论片段。
- 漫游页会申请浏览器后置摄像头权限并显示实时画面；拒绝权限、设备不支持或不安全来源时回退到夜景照片。实时画面与三颗不同距离和形状的演示锚点共用同一个取景坐标层，镜头缩放时泡泡会保持对齐；手绘 SVG 笔触、瞄准缩放、泡泡水进度和入场飞泡覆盖其上。捕捉时以渐变光液流将选中泡泡带到中央，点按后用语音合成试听，长按泡泡可看 Liquid Glass 留言。
- 左下角 Three.js EchoCaster 模型，可旋转、展开和收起；默认以观众正面展示 STL 本体，不再显示悬空独立手机；程序化虚拟手贴合柄位，呈现掌心包握、手指回扣的姿势。悬停或轻触模型标记可查看竖屏手机仓、上端出泡口和握柄设计说明。播放时手部轻微响应，装置吐出少量大颗泡泡。
- 录音页的泡泡外形会随 Demo 模拟的时长和音量起伏膨胀、抖动；发布后会进入个人泡泡场，并自动打开 EchoCaster 模型和播放发泡动画。
- 虚拟手由程序生成，用于说明持握方式，不代表真实手部追踪或实体设备联动。
- 桌面演示中的现场镜像，用于展示观众看到的大屏状态。
- SwiftUI Liquid Glass 视觉原型 `native/SoundscapeDemoView.swift`，同步展示异形泡泡、焦点轨道标签、AR 风格插画与扫描/缓冲转场；该文件仍未在 Xcode 工程中编译验证，原生视图没有配置照片资源。
- 首页采用 Y2K 屏保式弥散泡泡场；泡泡边缘使用低对比虹彩薄膜，不加厚重蓝圈。圆形泡泡继续使用球面文字轨道，心形、星形、花形、云朵形等异形泡泡沿 SVG 外轮廓环转标签；后侧文字绘制在透明泡泡后层并淡化，前侧文字叠到泡泡前层。焦点泡泡保留手动拖动文字轨道和留言细节，其他泡泡用短标签并降低刷新频率。泡泡按大小层级铺场；拖动泡泡时，现有圆形碰撞体会让其挤开邻近泡泡，CSS 形变和薄液膜强调接触方向。点按时 Canvas 2D 绘制短促收缩、朝触点打开的宽裂口、卷曲薄膜、冲击波和重力水滴；它是经过编排的视觉反馈，不是流体或薄膜物理仿真。漫游页使用提供的夜间林道照片，创作页使用留白天空照片；手绘星星只点缀录音泡泡，透明泡泡素材用于选中目标和回声榜缩略图。素材去向见 [`asset-use-map.md`](./asset-use-map.md)。

## 当前模拟

- AR 摄像头画面是真实浏览器视频流（需要 HTTPS 或 localhost 及用户授权）；泡泡锚点的位置、方向、距离和高度仍是屏幕坐标演示，不会跟随真实平面、相机姿态或 GPS 追踪。摄像头不可用时漫游回退到项目照片。
- 扫描、泡泡水加载、入场飞泡、泡泡捕捉光流和镜头缩放均为网页动效，不是 ARKit 检测或真实流体模拟。
- 共创背景使用项目提供的静态照片；并未采集真实地点数据。
- 捕捉动画由网页状态触发，不是 ESP32 实体按键输入。
- 泡泡点击使用中文语音合成朗读示例文案，不代表真实 UGC 录音播放；波形与播放状态用于演示。
- 录音流程是交互模拟，没有调用麦克风，也没有运行声纹模型。波浪形变由合成的音量节奏驱动，不读取真实录音。
- Three.js 装置使用提供的 STL 外形，材质分区是根据断开的几何壳体推定后应用的演示 CMF；页面不会控制真实装置吹泡泡。播放时的泡泡大小、路径和周期全部是模型动画。
- 首页和 AR 的异形轮廓、轨道标签及插画装饰由 CSS、SVG 和视图动画生成；AR 手绘笔触是定制 SVG，不依赖 p5.brush；moodboard 里的整页参考图/素材表不直接作为界面贴图。
- 浏览器演示没有账号、服务端、数据库和跨设备同步。

## 后续集成方向

1. iOS 原生工程与 ARKit 场景锚点，让泡泡锚定到真实平面并随相机移动。
2. 可靠的 GPS/方向定位策略，以及室内演示的高度或场景定位方案。
3. 手机与 ESP32 的 Wi-Fi 通信协议、设备状态和按键事件。
4. 音频录制、播放、声纹分离/其他人声处理及发布服务。
5. 真实吹泡泡装置与播放状态反馈。
6. 多人共选和大屏同步机制。

开源泡泡项目的参考和当前未引入的原因见 [`open-source-references.md`](./open-source-references.md)。

以上清单是方向，不代表已确定的技术选型或已完成能力。实现前应按 Demo Day 所需体验优先级逐项验证。
