# App UI 组图生成提示词

适用于生成同一产品的连续界面概念图。推荐先生成组图看结构，再逐屏生成精图。为保证一致性，每次都使用“统一母提示词 + 屏幕场景 + 负面提示词”。

需要单独生成背景、贴纸、标题情绪版和故事板素材时，使用 [`newjeans-inspired-ui-asset-pack.md`](./newjeans-inspired-ui-asset-pack.md) 资产包。

## 统一母提示词

```text
为“声景漫游”设计一张高完成度的原生 iOS App 界面。产品结合个人声音 Gallery、城市漫游、手机 AR 和实体声音装置：用户在 Gallery 回听自己捕捉或创作的声音；进入漫游后发现留在真实 GPS 位置的公共声音泡泡，用手机瞄准，再按装置物理按键捕捉。装置播放声音并吹出真实泡泡。用户也能录下一句话，留给后来路过的人。

iPhone 竖屏 9:19.5，单张完整 App 截图，不画手机外壳、不拼贴多页面。像真实 SwiftUI App：网格严谨、信息层级清晰、留白充足、简体中文清楚易读。

标志视觉是透明的肥皂泡：大小不一、远近错落、接近透明，只有细薄虹彩边缘、微弱折射和珍珠高光。按声音类型用低饱和玫瑰粉（人声）、冰天蓝（环境声）、淡紫（碎念）变化泡泡的薄膜与内层光；不使用不透明彩球、卡通球或粗霓虹轮廓。

视觉基调为“奶油纸 × 天空蓝 × 森林绿 × 荧光柠檬绿点题”，结合手持数码相机颗粒、夏日直闪、Y2K 青春编辑拼贴、复印纸边和手绘箭头。首页是个人声音 Gallery，不显示地图、地点和附近距离；内容类型通过透明泡泡颜色与薄膜材质区分。AR 漫游页转为深森林取景和柠檬绿准星。Liquid Glass 只用于筛选、播放器、状态胶囊和导航；贴纸、纸片和照片框负责增加随手拼贴感。

使用接近 SF Pro / 苹方的字体，标题轻，重点清楚，文案精简。视觉高级、诗意、令人惊艳，但不做儿童游戏或科幻仪表盘；不照搬 Pokémon 或任何现有 App。
```

## 组图总提示词

```text
生成一张 16:9 横向产品视觉提案板，2 行 × 4 列展示同一款 App 的 8 个 iPhone 竖屏界面，尺寸、字体、色彩、玻璃材质和导航一致，阅读顺序从左到右、从上到下。展示完整体验：01 个人声音 Gallery；02 AR 城市漫游；03 泡泡详情与多人共选；04 按下实体键后的捕捉动画；05 装置播放声音并吹出真实泡泡；06 录下一句话；07 声音处理与位置发布确认；08 个人声音图鉴筛选状态。屏幕之间用极细的编号或连接线体现流程，留白明确，不加大段说明。各屏都是可实现的真实 App UI，不是概念海报。
```

## 单屏场景提示词

### 泡泡首页

```text
个人声音 Gallery 首页，完全不显示定位、街区名称、地图或距离。暖奶油纸色背景，叠一层非常浅的夏日数码照片柔光和纸张颗粒。顶部是荧光柠檬绿小档案贴“FIELD NOTES / VOL.01”和轻量设备连接状态。标题“我的回声”采用粗圆角中文黑体，回声二字下方有一笔不规则荧光笔标记；副标题“05 段声音 · 03 种内容”。下方是“全部 / 人声 / 环境声 / 碎念”筛选，当前项为柠檬绿标签。主视觉排布 4 到 6 颗大小不同、接近透明的肥皂泡，每颗有短标题、声音类型和档案序号；最近收录的第一颗放在暖白纸卡中，卡片轻微错位并带一小段半透明胶带。人声用柔和玫瑰薄膜，环境声用冰天蓝，碎念用淡紫。底部播放器保留轻薄 Liquid Glass，主按钮用荧光柠檬绿。主导航为“泡泡 / 漫游 / 共创”，当前选中泡泡。整体像个人声音 zine，清爽、随手、有留白。
```

### AR 漫游与目标选择

```text
沉浸式城市 AR 取景，真实的深森林绿街道或社区绿地，有地面、树影和远近纵深，不要地图底图。画面像傍晚手持数码相机拍摄，轻微颗粒与直闪高光。多颗透明声音泡泡分布在不同距离与视觉高度；主目标位于视线高处，显示“二层回声 · 8 m”。中央使用细线柠檬绿取景准星与四角 viewfinder 标记，右侧有缩放。顶部是小型时间码与定位/设备状态；底部目标卡为奶油纸色，显示声音短句、作者、时长和共选人数，主操作“按装置键捕捉”。不显示底部主导航，保留取景空间。
```

### 泡泡详情与现场共选

```text
在仍能看见城市 AR 背景的状态下，底部弹出约占屏幕 42% 的轻薄玻璃抽屉。显示小泡泡缩略图、标题“二层回声”、短句“风从河面来，像一句没说完的话。”、作者“林 · 昨日留下 · 12 秒”、音频波形、4 个共选头像和“大家想收这颗”。主按钮“瞄准这颗”，次动作“稍后再听”。表达“已选中、等待捕捉”，不要误画成捕捉成功。
```

### 捕捉与播放

```text
深青 AR 城市背景中，选中的透明泡泡被拉成细薄虹彩光丝，沿空间方向吸向装置状态区。显示“收到了 · 风从河面来”；底部显示“装置正在播放 · 12 秒”和动态波形，装置图标旁有几颗真实透明小泡泡飘出。表现手机界面与实体装置同步，不要爆炸、金币或魔法光束。公共原泡泡仍留在原坐标，稍后可由其他人发现。
```

### 录音与发布

```text
暖奶油纸色背景，带一点叶片影子和复印纸颗粒，标题“留一句”采用粗圆角字体。角落有“FIELD RECORDING / 01”和小型红色 REC 点。中央透明泡泡随着人声轻柔脉动；下方是荧光柠檬绿录音键、短音频波形和计时器。录后展示试听波形与短句文本，再显示“江湾 · GPS 点位已锁定”“公开给路过的人”，主按钮“留在这里”。用一张轻微错位的纸片承载录音状态，Liquid Glass 用于少量选择控件，不像专业音频工作站。
```

## 弹窗组件组图提示词

```text
生成一张 2 行 × 3 列的 iOS Liquid Glass 弹窗组件板，背景为轻微模糊的城市漫游画面，六个弹窗风格、字号、圆角和材质一致，尺寸不遮满屏幕。依次表现：1 目标已选中、等待实体按键；2 捕捉成功、设备播放与吹泡泡；3 只保留录制者声音、试听处理结果；4 确认 GPS 点位和公开范围；5 ESP32 设备搜索、已连接、重试状态；6 漫游轻任务进度。每个弹窗只有一个主动作、一个必要次动作和一个核心状态，文字清晰、轻薄留白，不堆说明。
```

## 负面提示词

```text
不透明彩球、卡通宠物、儿童玩具风、荧光赛博朋克、满屏粗霓虹、所有模块都套玻璃卡片、拥挤地图 POI、复杂排行榜、积分金币、乱码小字、Lorem ipsum、多余按钮、水印、品牌 Logo、iPhone 外壳、多屏拼贴（单屏提示中未要求组图时）。
```
