# 青春胶片感 UI 文生图资产包

这套提示词把参考图里的视觉语言提炼成适合“声景漫游”的原创方向：轻松的 Y2K 青春编辑感、夏日自然光、手持相机颗粒、森林暗场、荧光柠檬绿标题和 scrapbook 拼贴。保留产品自己的透明声音泡泡、声音档案与实体捕捉语义。

## 统一视觉母提示词

```text
为原创产品“声景漫游”生成一组统一的视觉资产。总体方向是轻松、亲密、带一点 1990s/early-2000s 青春音乐杂志与手持数码相机感：夏日树影、直闪照片、轻微失焦、真实胶片颗粒、浅奶油纸张、叶片绿、天空蓝和少量高亮荧光柠檬绿；搭配不规则剪贴照片、复印纸边、手写箭头、圆点、短划线和小尺寸贴纸。氛围自然、好奇、像朋友留下的一卷声音日记，不像商业广告大片。

声景漫游的核心图形是透明肥皂泡：大小不一，薄膜边缘有克制的粉蓝虹彩，内部留白通透。人声泡泡微微偏玫瑰粉，环境声泡泡微微偏天蓝，碎念泡泡微微偏淡紫；色彩是材质暗示，不填成不透明实心球。页面文字和交互控件由真实 App 排版实现；生成背景素材时不要生成文字。

统一使用暖白纸色 #F7F4E9、森林墨绿 #203B2E、天空蓝 #C8E3F2、柔粉 #EFC5D4、低饱和叶绿，以及少量荧光柠檬绿 #D9F04D。暗场可以用森林绿和午夜蓝，但保持泡泡轮廓可辨。光线有直闪的微光晕和轻微色偏，纹理细腻，构图有呼吸空间，适配移动端裁切。

视觉应显得随手、年轻、轻微古怪、真实可触，不要过分精致的奢侈品广告感。所有品牌符号、字标、人物和排版均原创。
```

## 资产 01：个人声音 Gallery 首页氛围底图

```text
生成一张 9:16 竖屏移动 App 首页背景素材，不包含手机外框、UI、文字或 Logo。夏日午后逆光穿过树叶，浅奶油色天空与柔淡的天蓝光雾交叠，画面边缘有少量树影和柔焦高光，中间 60% 保持干净浅色留白，适合叠加透明声音泡泡与深色标题。像 2000 年前后便携数码相机拍到的生活片段，轻微颗粒、细小镜头光晕、自然曝光，不要强烈粉色滤镜。使用青春音乐杂志的随手照片感，避免可识别地标与人脸。
```

建议：9:16，1179 × 2556，JPG；正文文字区域保持低纹理和高对比。

## 资产 02：漫游 AR 森林/街道底图

```text
生成一张 9:16 竖屏真实环境照片，供手机 AR 漫游页面做静态演示底图。傍晚蓝调时刻的城市小路或社区绿地，近处有深绿树叶和灌木，远处透出少量冷蓝天空与暖色路灯；摄影像手持小型数码相机直闪，略有动态模糊、自然颗粒、暗角和轻微过曝。画面下半部保留可识别的人行道/地面，中央偏上留出一处干净空间供叠加透明目标泡泡。真实、有纵深、带一点梦境般的不确定感，但不出现人、车牌、品牌标志、可读文字或地图标注。
```

建议：9:16，1179 × 2556，JPG；另外生成一张 16:9 大屏裁切版本，主体位置保持在中央偏上。

## 资产 03：手绘贴纸透明素材页

```text
生成一张 1:1 透明背景 PNG 贴纸素材页，包含 16 个互不重叠的小型原创装饰：手绘四角星、声音波纹、涂鸦箭头、简化的录音红点、歪斜的荧光柠檬绿标签、透明泡泡轮廓、胶片打孔边、手写短线和小圆点。线条像用黑色签字笔画在复印纸上，边缘略有复印机颗粒；少量奶油白、叶绿、天蓝和荧光柠檬绿填色。每个贴纸独立、四周留足透明边距，轮廓清楚，便于切图。图案原创，不使用兔子吉祥物或任何现成团体标志，不出现文字。
```

建议：2048 × 2048，透明 PNG；生成后按单个图案切成 SVG/PNG，小贴纸控制在 16–32 px。

## 资产 04：肥皂泡材质素材组

```text
生成 6 颗不同大小的真实透明肥皂泡，单独漂浮在纯透明背景上，彼此不要重叠。每颗泡泡有极薄的虹彩边缘、柔和高光、轻微折射和自然的不规则球面；整体几乎透明。分别让虹彩隐约偏冰蓝、玫瑰粉、淡紫、淡薄荷、暖金和中性白。保持球体干净、轻盈、像夏日阳光下拍摄的真实泡泡；不要卡通眼睛、面部、实心渐变填色、粗描边或发光球体。每个泡泡独立成层，适合作为界面装饰 PNG。
```

建议：每颗单独生成 1024 × 1024 透明 PNG；实时代码里的可交互泡泡继续用 SwiftUI/CSS 绘制，位图用于封面与装饰。

## 资产 05：原创“声景漫游”标题字形情绪版

```text
设计“声景漫游”四个简体中文字的原创标题字形情绪版，横向排版，字形像年轻音乐杂志封面上的手绘粗记号笔标题：笔画有一点不齐、亲和、略有倾斜，仍然清楚可读。深森林墨绿字形，局部可用荧光柠檬绿做一条不规则荧光笔底线；纸张背景为暖奶油白，周围仅有少量手绘星点和短箭头。风格轻松、真实、带复印纸颗粒，不照搬任何现成乐队字标、字体或 Logo。只生成这四个准确汉字，不加其他英文或图形标志。
```

说明：文生图适合探索标题字形和字标情绪，不会产出可安装字体文件。若要生成实际字体，使用有明确授权的字库制作工具，并单独检查字形质量与商用许可。

## 资产 06：字体与版式情绪板

```text
生成一张横向 4:3 中文移动 App 字体系统情绪板，暖奶油纸色底，青春音乐杂志与数码相机档案的混合气质。展示三种原创排版方向：A 深森林绿的超粗中文标题“我的回声”；B 简洁易读的无衬线正文“把声音留给后来的人”；C 荧光柠檬绿小号等宽档案标记“FIELD NOTES / VOL.01 / SIDE A”。用清楚的字号阶梯、字重和字距样例呈现，旁边可有少量复印颗粒和一条手绘箭头。保持中文准确可读，避免复杂段落、花体难读字和任何现成品牌字标。
```

建议以图像确定气质，落地时使用系统字体组合：中文标题可用系统圆体/黑体，信息标签用系统等宽字体，正文优先保证可读性。

```text

```

## 统一负面提示词

```text
现成乐队 Logo、NewJeans 字标或商标、官方兔子吉祥物、成员肖像或仿真人脸、照搬既有专辑封面/广告、厚重赛博朋克霓虹、奢侈品棚拍、过度粉紫梦幻滤镜、卡通实心泡泡、粗发光描边、过度模糊、密集小字、错误中文、乱码、假文字、地图 POI、手机外框、水印、重复元素、贴纸互相重叠、过多装饰遮挡主内容。
```

## 推荐生成顺序

1. 先生成“字体与版式情绪板”和“故事板拼贴背景”，确定文字重量和纸张/胶片质感。
2. 再分别生成首页底图、漫游底图与贴纸素材，所有背景图保留 UI 留白区。
3. 最后生成泡泡素材与捕捉分镜，用在非交互装饰和演示海报；实际可点按泡泡仍由代码绘制，保证清晰度和动画表现。
4. 图片模型生成的字不用于最终按钮/正文；在 SwiftUI 和网页里用真实字体重新排版。
