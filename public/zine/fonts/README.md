These web font files are subsets of the official LXGW Marker Gothic v1.012 and LXGW WenKai GB v1.530 releases. They include the characters used by the current ten Zine pages in `src/zine/content.js` and `src/zine/page-art.js`; regenerate the subsets if page copy or drawn annotations change. The full upstream SIL Open Font License 1.1 texts are included below.

The WenKai GB subset is used only as a web-delivered Zine font and is not provided as an installable desktop font, consistent with the additional permission in its upstream license.

`SpecialElite-Regular.ttf` is from the official Google Fonts repository and is distributed under Apache License 2.0. Its license is included as `LICENSE-Special-Elite.txt`.

The QWERTYpe font supplied by the user has no license file or public embedding permission and is not included in the public assets.
