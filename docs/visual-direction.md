# 视觉方向

## 核心意象

把声音做成停留在城市里的透明泡泡：薄、轻、大小不一，带细微虹彩边缘和柔和折射。泡泡是界面的视觉焦点，玻璃面板只承载操作和状态。

## 视觉语言

- **首页与共创**：雾白、浅薄荷、水岸天光、大面积留白。
- **AR 漫游**：更深的青绿色城市取景，空间纵深明显，泡泡目标清楚。
- **材质**：Liquid Glass 用于底部导航、浮层、状态胶囊和主要控件；内容表面保持轻薄。
- **层级**：一屏一个主焦点；标题轻，状态清楚，辅助文案短。
- **动效**：泡泡轻浮、准星对焦、被捕捉时沿方向吸入、播放时波形与实体泡泡同步出现。
- **颜色**：以中性色和深青为基础，冰蓝、淡粉、香槟金只点缀虹彩泡泡和关键反馈。

## 避免

- 不透明实心球、卡通宠物、过强霓虹和赛博朋克风。
- 所有模块都套玻璃卡片、满屏说明、复杂地图点位或排行榜。
- 把真实 GPS 位置泡泡表现为一次性消耗品。
